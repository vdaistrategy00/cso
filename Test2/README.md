## 프로젝트 개요

Test1의 5페이지 구성을 **하나의 스크롤형 랜딩 페이지**로 재구성한 데모입니다.
NQ AI 프로세서, 8K 업스케일링, AI 사운드 등 핵심 가치를 빠르게 전달하도록 설계했습니다.

### 페이지 구성 (한 화면, 스크롤)

| 섹션 | 내용 |
|------|------|
| **Hero** | 메인 카피 + TV 목업 + CTA 버튼 |
| **핵심 기능** | NQ8 AI Gen3, AI 사운드, AI 모션 등 6개 카드 |
| **통계** | 8K · 512 뉴럴넷 · 144Hz · 99% 명암 |
| **AI 기술** | 업스케일링 · Quantum Matrix Pro · HDR 8K+ |
| **모델 비교** | Neo QLED 8K / 4K / OLED 비교 표 |
| **상담 신청** | 이름·연락처 입력 폼 (데모 동작) |

## 주요 특징

- 🎨 **모던 다크 UI** — 그라데이션 텍스트, 글래스모피즘 네비게이션
- 📱 **반응형 디자인** — 모바일 햄버거 메뉴 포함
- ✨ **스크롤 애니메이션** — IntersectionObserver 기반 등장 효과
