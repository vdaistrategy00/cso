# 🎮 테트리스 웹 게임

순수 HTML/CSS/JavaScript로 만든 **단일 파일** 테트리스 게임입니다.
설치·서버 없이 `index.html` 을 더블클릭하면 바로 실행됩니다.

## ▶️ 실행하기 — index.html 더블클릭

내 컴퓨터에 있는 **`index.html` 파일을 더블클릭**하면 기본 브라우저에서 게임이 바로 실행됩니다. 🎉
외부 파일·인터넷 연결이 전혀 필요 없는 단일 파일이라 어디서든 더블클릭만으로 동작합니다.

> 💡 더블클릭했을 때 코드 에디터로 열린다면, 브라우저를 먼저 켠 뒤
> `index.html` 을 브라우저 창으로 **끌어다 놓거나(드래그&드롭)**,
> 브라우저에서 `Ctrl + O` (Mac은 `Cmd + O`) 로 파일을 선택해 여세요.

### 📥 아직 파일이 컴퓨터에 없다면?
GitHub 웹페이지에서는 `index.html` 을 클릭해도 코드만 보일 뿐 실행되지 않습니다.
먼저 파일을 내 컴퓨터로 가져와야 합니다 (둘 중 편한 방법):

- **저장소 ZIP 받기** — 저장소 상단 `Code ▸ Download ZIP` → 압축을 풀면 `index.html` 이 들어 있습니다.
- **파일 하나만 받기** — [index.html 열기](./index.html) → 우측 **Download raw file(⬇️)** 버튼.

가져온 뒤에는 위처럼 **더블클릭**만 하면 됩니다.

## 🕹️ 조작법

| 키 | 동작 |
|----|------|
| `←` `→` | 좌우 이동 |
| `↓` | 빠르게 내리기 (소프트드롭) |
| `↑` | 회전 |
| `Space` | 하드드롭 (즉시 떨어뜨리기) |
| `P` | 일시정지 / 재개 |

## ✨ 기능

- 표준 7가지 테트로미노 (I, O, T, S, Z, J, L) — 각각 고유 색상
- 회전 시 벽 차기(wall kick) 보정
- 고스트 블록 — 블록이 떨어질 위치 미리보기
- 점수 · 라인 · 레벨 시스템 (라인 10줄마다 레벨업, 낙하 속도 증가)
- 다음 블록 미리보기
- 게임 오버 / 재시작
